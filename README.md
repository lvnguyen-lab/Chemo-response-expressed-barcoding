# Chemo-response-expressed-barcoding
Computational analysis for expressed cellular barcoding combined with scRNAseq for human breast PDTX models treated with chemotherapy, related to manuscript by Kronheim S et al.

Analysis of bulk response to treatment is performed with the "tumor_volume_bulk_response.ipynb" script, which requires tumor volume over time excel sheets and outputs visualizations of growth curves and growth rate changes from pre- to post-treatment for each xenograft.

Analysis of amplicon sequencing and assignment of clonal response to treatment is performed with the "amplicon_analysis.ipynb" script. This script requires processed amplicon sequencing data and outputs data visualizations as well as a csv file containing all barcode clones with their responses to both paclitaxel and carboplatin treatment. The script also corrects for multiple integrations, removing all barcodes in a multiple integration set except for the one with the most sequencing reads.

Model of expected percent emerging clones assuming sequencing and sampling limitations alone account for emergence and no differential fitness is performed with the "amplicon_emergence_poisson_model.py" script. This script requires csvs with clone size, sequencing information and xenograft cell yield, and spike-in information (found in the data_files/poisson_model folder) to model the expected percent emerging clones based on the primary clones, cell yield, and spike-in control sequencing reads. This script outputs the modeled percent emerging for each xenograft and a comparison of this percent with the observed percent emerging as well as measures of uncertainty 

Analysis of barcodes that belong to multiple-integration sets and assignment of response to treatment to scRNAseq cells is performed with "parse_barcodes_for_scRNAseq.ipynb" script. This script requires csv files with all scRNAseq cells and their associated barcodes, as results from the "associate_barcodes_with_10x_cells.R" script published in Shin HJ et al. STAR Protocols 2025 (PMID: 41317321), and a csv with all barcodes and their responses to treatment as output from the "amplicon_analysis.ipynb" script. This script outputs a summary of barcodes that were integrated together as well as csv files with all cells from scRNAseq and their barcode-related metadata for addition to appropriate Seurat objects.
